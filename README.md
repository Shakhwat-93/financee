# হিসাব খাতা — প্রিমিয়াম মোবাইল অ্যাপ (Android APK & PWA)

আয়, অ্যাড খরচ আর ক্লায়েন্ট পেমেন্টের হিসাব রাখার আল্ট্রা-পাওয়ারফুল মোবাইল অ্যাপ্লিকেশন। এটি সরাসরি ফোনে `.apk` হিসেবে ইনস্টল করা যায় এবং যেকোনো ব্রাউজারে ইনস্টলযোগ্য PWA হিসেবেও চালানো যায়।

---

## 🚀 প্রধান প্রধান ফিচারসমূহ

- **ডুয়াল কারেন্সি সাপোর্ট**: ডিফল্ট হিসেবে **টাকা (৳ BDT)** এবং সেটিংসে এক ক্লিকে **ডলার ($ USD)** পরিবর্তনের সুযোগ।
- **ডিরেক্ট অ্যান্ড্রয়েড APK বিল্ডার (GitHub Actions)**: কোনো লোকাল অ্যান্ড্রয়েড স্টুডিও ছাড়া সরাসরি গিটহাবে পুশ করলেই রেডি-টু-ইনস্টল `HisabKhata.apk` ডাউনলোড লিংক তৈরি হয়।
- **ইন-অ্যাপ ক্যালকুলেটর কি-প্যাড**: স্ক্রিন থেকে কোনো সাধারণ কি-বোর্ড উঠবে না, কাস্টম কি-প্যাডে সরাসরি যোগ-বিয়োগ-গুণ-ভাগ (`143 × 2 = 286`) করা যায়।
- **সোয়াইপ-টু-সেভ**: টাকার ঘরে ডানে আঙুল টানলেই (বা Enter চাপলে) হ্যাপটিক ফিডব্যাক সহ সবুজ সাকসেস স্ক্রিনে সেভ হয়।
- **ডেটা নিরাপত্তা ও ব্যাকআপ**: 
  - সম্পূর্ণ ডেটা `.json` ফাইল হিসেবে সরাসরি ফোনে ডাউনলোড।
  - আগের যেকোনো ব্যাকআপ থেকে **"ব্যাকআপ রিস্টোর"** করার সুবিধা।
  - সব লেনদেন এক ক্লিকে **Excel / CSV** ফাইল হিসেবে এক্সপোর্ট।
  - **হোয়াটসঅ্যাপ / মেসেঞ্জারে মাসিক রিপোর্ট শেয়ার** করার অপশন।
- **অ্যান্ড্রয়েড নেটিভ এক্সপেরিয়েন্স**:
  - ফিজিক্যাল ব্যাক বাটন চাপলে শিট বা মোডাল বন্ধ হবে।
  - এজ-টু-এজ ডার্ক থিম ও স্ট্যাটাস বার কালার ম্যাচিং।
  - লং-প্রেস অ্যাপ শর্টকাটস: আইকনে চাপ ধরে রাখলে সরাসরি "নতুন আয়", "নতুন খরচ" বা "রিপোর্ট" খোলার অপশন।

## 📱 কীভাবে আপনার ফোনে APK ইনস্টল করবেন (GitHub Actions)

আপনার কম্পিউটারে কোনো Java বা Android Studio সেটআপ করার প্রয়োজন নেই! GitHub Actions ক্লাউডেই সম্পূর্ণ APK বানিয়ে দেবে:

1. **গিট ইনিশিয়ালাইজ করে পুশ করুন:**
   ```bash
   git init
   git add .
   git commit -m "হিসাব খাতা মোবাইল রিলিজ"
   git branch -M main
   git remote add origin https://github.com/আপনার-ইউজারনেম/আপনার-রিপোজিটরি.git
   git push -u origin main
   ```

2. **APK ডাউনলোড করুন:**
   - আপনার GitHub রিপোজিটরির **Actions** ট্যাবে যান।
   - লেটেস্ট ওয়ার্কফ্লো রানটিতে ঢুকুন।
   - পেজের নিচে **Artifacts** সেকশনে `HisabKhata-Android-APK` পাবেন।
   - জিপ ফাইলটি ডাউনলোড করে আনজিপ করলেই পাবেন `HisabKhata.apk`।
   - ফাইলটি আপনার মোবাইলে নিয়ে ১-ট্যাপে ইনস্টল করে নিন!

## 💻 লোকালি চালানো

```bash
# ডিপেন্ডেন্সি ইনস্টল (যদি না থাকে)
npm install

# লোকাল ডেভ সার্ভার
npm start
```
